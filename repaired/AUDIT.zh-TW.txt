修正內容

addi：清除錯誤的 MemWrite，加入對齊位址的 sentinel 回歸，避免不對齊存取
被拒絕後把原錯誤掩蓋。byte address 20 對應 memory[5]。

記憶體：lw/sw 依 base+signext(imm) 計算 byte address，再除以 4 索引 word。
完整初始化到最後一格，檢查位址範圍與對齊，支援簡報的 address 400 迴圈。
保留 A 版：64 instruction words、256 data words；保留 B/C：各 1024 words。
新 reference：instruction/data 各 1024 words。

ALU 與暫存器：signed slt 回傳 0 或 1，addi 正確符號延伸，保護 register 0。
不將資料值等於某個數字當作 forwarding 相依條件。

控制流程：j 與 beq 有正確位址路徑，taken branch／jump 清除較年輕指令，
錯誤路徑不能寫暫存器或 memory；較舊的 taken branch 優先於較年輕 jump。
保留 pipeline 在 MEM 解決 branch、ID 解決 jump；新 reference 在 EX 解決
branch／jump，清除兩個較年輕階段。皆採無 delay slot 語意。

Hazard：依來源與目的暫存器編號 forwarding，每個運算元分開選擇，較新 EX/MEM
優先於 MEM/WB。load 的 EX/MEM address 不可當成 load data。store data 也有
forwarding，ALUSrc immediate 在正確位置選擇，不會被 forwarding 覆蓋。
load-use 會 hold PC／IF-ID 並插入 bubble，並排除 $zero 與沒有使用的來源欄位。

Level B 仍是沒有一般 data-hazard 自動處理的基本五階段管線，需使用 NOP 排程。
保留 B 範例使用 3 個 NOP；新 reference 的測試使用 4 個 NOP。Level C 則以
未插入相依 NOP 的指令串驗證，沒有把排程後的成功當作自動 hazard 合格。

新 reference 使用同步 active-high reset，清 PC／registers／pipeline valid，
保留資料 RAM；舊版維持原 active-high 非同步 reset，清除其資料 RAM。
新版本 initial 區塊提供確定的內建程式與 RAM 初值，不依靠未初始化的 X。
